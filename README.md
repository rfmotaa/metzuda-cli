# Metzuda

Security scanner built specifically for AI-generated code.

![PyPI](https://img.shields.io/pypi/v/metzuda)
![License](https://img.shields.io/github/license/rfmota/metzuda)
![Python](https://img.shields.io/pypi/pyversions/metzuda)

Metzuda is a zero-config security scanner designed to catch vulnerabilities in code generated by AI coding assistants (like Cursor, Claude Code, GitHub Copilot). It combines fast, local static analysis (Semgrep rules calibrated for AI patterns) with optional, targeted semantic analysis (Anthropic Claude API) to identify logical flaws that rules miss. 

For every severe vulnerability detected, Metzuda generates a tailored fix prompt ready to be pasted back into your AI coding assistant.

---

## What it Detects

* **Hardcoded Secrets**: AWS keys, database connection strings, and Stripe API keys introduced by rapid AI generation fallbacks.
* **SQL Injection**: Dynamic queries constructed via string concatenation or template literals.
* **Insecure CORS**: Broad wildcard origins (`origin: '*'`) in API routes.
* **Dynamic Code Execution**: Dangerous uses of `eval()`, `exec()`, or `new Function()` containing variables.
* **Missing & Broken Auth**: Public routes missing authentication middleware or IDOR vulnerabilities (Insecure Direct Object References).


## Quick Start (Exactly 3 Commands)

Initialize Metzuda in your repository root, scan your code, and retrieve a fix prompt:

```bash
# 1. Initialize configuration and state
metzuda init

# 2. Run a full security scan
metzuda scan

# 3. View the generated LLM fix prompt for findings
metzuda fix
```

## CI/CD & Hook Integration

### GitHub Actions
To scan every pull request and upload results to your repository's Security tab:

```yaml
# .github/workflows/metzuda.yml
name: Metzuda Security Scan
on: [push, pull_request]
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: rfmota/metzuda-action@v1
        with:
          fail-on: HIGH         # Fails step if HIGH/CRITICAL findings exist
          no-ai: true           # Fast local scan (no Anthropic API keys required)
          anthropic-api-key: ${{ secrets.ANTHROPIC_API_KEY }}  # Optional for AI analysis
```

### Pre-commit Hook
To scan changed files automatically before every commit:

```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/rfmota/metzuda
    rev: v0.1.0
    hooks:
      - id: metzuda
        args: [--no-ai, --fail-on, HIGH]
```

## Configuration (`.metzuda/config.yml`)

The configuration file is generated upon running `metzuda init`. You can customize settings directly:

```yaml
# Metzuda configuration schema version
version: "1"

project:
  # The primary language of your project (auto | javascript | python | java)
  # If "auto", Metzuda will count file extensions to determine the target language.
  language: auto

scan:
  # Minimum finding severity that will cause 'metzuda scan' to exit with code 1
  severity_threshold: HIGH

  # Run Layer 2 semantic checks via the Anthropic Claude API for severe findings
  ai_analysis: true

  # Maximum lines of code sent to the Anthropic API as context surrounding the finding
  max_context_lines: 150

ignore:
  # Paths and files excluded from the scan walking process
  paths:
    - node_modules/
    - dist/
    - build/
    - out/
    - .next/
    - .nuxt/
    - .svelte-kit/
    - coverage/
    - .cache/
    - __pycache__/
    - .venv/
    - venv/
    - env/
    - .pytest_cache/
    - .mypy_cache/
    - target/
    - .gradle/
    - bin/
    - .metzuda/
```
